# Admin guide (one page, fill in as features land)

## Add a question
1. Admin > Soal > New. Pick the release date (opens 04:00 WIB, closes 24 h later).
2. Write the problem in LaTeX with the toolbar; check the live preview.
3. Set the answer key (accepted answers) and the mark scheme (criteria that add up to 5).
4. Optional: diagram image, topic, difficulty, worked solution.
5. Watch for the "no question scheduled for tomorrow" warning.

## Grade
1. Admin > Koreksi. Pick a question (after it closes).
2. Review the auto-verdict; confirm or override.
3. Tick mark-scheme criteria, add private feedback, save. `Enter` jumps to the next ungraded.
4. The answer key and mark scheme are shown on the same screen. If two admins save the same submission, the last save wins and the screen shows who saved last.

## Manage members
- Import roster CSV: temporary passwords appear once. Download them and hand them out.
- Reset password: a new temporary password appears once.
- Edit name and class (members cannot edit these themselves).
- Deactivate/activate, promote to admin.
- Set the OSN date.
